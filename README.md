Entry for the make.fun bounty
[Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d):
write the funniest one-line patch note for a bug in real life or human
biology, 160 characters max.

## The entry

> v3.5.4: fixed a bug where the thigh hallucinated incoming calls. No vibration motor was ever installed.

The bug is phantom vibration syndrome: the thigh reports an incoming
phone call that never happened, even though the body ships with no
vibration motor at all.

## Run

```sh
python3 main.py
```

Writes the single-line patch note to `/output/entry.txt` (103 characters,
one line, valid UTF-8). Standard library only — no dependencies.
